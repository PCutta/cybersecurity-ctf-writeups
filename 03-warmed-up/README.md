## Challenge Objective

Convert the hexadecimal value `0x3D` (base 16) into decimal (base 10).

## Approach

Hexadecimal is a base-16 numbering system that uses digits 0–9 and letters A–F.

The letters represent decimal values:

- A = 10
- B = 11
- C = 12
- D = 13
- E = 14
- F = 15

The prefix `0x` indicates that the number is hexadecimal.

To convert `0x3D` into decimal, I used positional values.

The first digit (3) occupies the 16s position, while the second digit (D) occupies the 1s position.

The calculation is:

(3 × 16) + (13 × 1)

48 + 13 = 61

Therefore:

**0x3D in hexadecimal = 61 in decimal**
