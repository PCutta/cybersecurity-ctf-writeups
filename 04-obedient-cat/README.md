# Obedient Cat — Reading a Flag File

**Platform:** CyLab Security Academy
**Category:** General Skills
**Difficulty:** Easy
**Status:** Solved

## Challenge Objective

Download the provided file and locate the hidden flag.

## Approach

The challenge provided a downloadable file containing the flag.

I completed the following steps:

1. Opened the challenge in CyLab Security Academy.
2. Clicked the provided file link.
3. Downloaded the file to the computer.
4. Opened the downloaded file using Windows Notepad.
5. Examined the file's plaintext contents.
6. Located the flag beginning with `academy{`.
7. Submitted the flag to complete the challenge.

## Result

Successfully located and submitted the flag by reading the contents of the downloaded file.

## Skills Practiced

- Downloading challenge files
- Inspecting plaintext files
- Using Windows Notepad
- Identifying CTF flag formats
- Basic file analysis

## What I Learned

This challenge demonstrated that not every cybersecurity challenge requires advanced tools or programming.

Sometimes the solution involves carefully examining a file and understanding the information it contains.

I also gained experience recognizing the flag format used by CyLab Security Academy.
