# 2warm — Decimal to Binary Conversion

**Platform:** CyLab Security Academy

**Difficulty:** Easy  
**Status:** Solved

## Challenge Objective

Convert the decimal number 42 (base 10) into binary (base 2).

## Approach

Binary uses only two digits: 0 and 1.

Each binary position represents a power of two.

To convert 42 into binary, I identified which powers of two add up to 42.

| Place Value | 32 | 16 | 8 | 4 | 2 | 1 |
|---|---|---|---|---|---|---|
| Binary Digit | 1 | 0 | 1 | 0 | 1 | 0 |

32 + 8 + 2 = 42

Therefore:

**42 in decimal = 101010 in binary**
